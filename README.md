# BB84 Quantum Cryptography Protocol

This repository contains an implementation of the BB84 Quantum Key Distribution (QKD) protocol using Python and Qiskit.

## Overview

BB84 is the first quantum cryptography protocol proposed by Charles Bennett and Gilles Brassard in 1984. It allows two parties (Alice and Bob) to establish a secure cryptographic key using quantum mechanics.

## Features

- BB84 protocol simulation
- Random basis selection
- Key generation
- Basis reconciliation
- Secure key extraction
## Requirements

- Python 3.x
- Qiskit
- NumPy
- Matplotlib
